Approach

How I work a ticket

  1. Triage

    Set priority by impact. Anything touching payroll, pay or a worker's access moves to the front of the queue.

  2. Reproduce

    Open the worker, the transaction and the business process history. Confirm what happened before trusting the ticket description.

  3. Isolate the cause

    Decide which layer failed: worker data, configuration, eligibility, security or the integration. Check whether other workers are affected.

  4. Fix in Sandbox first

    Any configuration change is tested in Sandbox with real cases, including cases that should not change.

  5. Correct and reconcile

    Fix the affected transactions in Production and compare before and after with a report or an Excel reconciliation.

  6. Document and prevent

    Write the SOP or knowledge article, and add an audit report or rule so the issue is caught earlier next time.

Evidence

How I measure outcomes

Every figure on this page comes from Jira or a Workday report, counted the same way each month so the numbers can be compared.

98% SLA compliance
Jira filter of tickets resolved in the month. Tickets resolved inside the SLA target for their priority (P1 to P4), divided by all tickets resolved. Time spent waiting on the requester is excluded.
30+ tickets a month
Count of Jira tickets assigned to me and moved to Resolved in the calendar month, split by module label so I can see where the volume comes from.
35% fewer repeat approval tickets
Count of Jira tickets labelled as approval or routing questions for the job change process. I compared the three months before the condition rule went live with the three months after, using the same filter for both periods.
Fix confirmed
A ticket is closed only after a Workday audit report or an Excel reconciliation shows zero remaining exceptions, and the requester confirms the result.
Recurrence
Reopened tickets and new tickets with the same root cause are tracked by label. A cause that appears three times becomes a candidate for a configuration fix, an audit report or an SOP.
